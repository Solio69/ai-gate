# AI Gate

Минимальное приложение для тестового задания: анонимный запрос к бесплатному маршруту OpenRouter с потоковым ответом. Завершённая пара запрос–ответ сохраняется в PostgreSQL под ID cookie-сессии и в локальной истории браузера.

## Локальный запуск

Нужны Node.js 24, npm и Docker Desktop.

1. Скопируйте `.env.example` в `.env` и задайте `OPENROUTER_API_KEY`. Сгенерируйте случайное значение `COOKIE_SECRET` (например, 32 случайных байта в hex). Файл `.env` игнорируется Git.
2. Запустите базу: `docker compose up -d db`. Контейнер использует локальный порт `127.0.0.1:5433`, чтобы не занимать стандартный `5432`.
3. Установите пакеты: `npm ci`.
4. В двух терминалах запустите `npm run dev:api` и `npm run dev:web`.
5. Откройте [http://127.0.0.1:5173](http://127.0.0.1:5173).

Если ключ OpenRouter ещё не задан, форма откроется, а отправка запроса сообщит об отсутствии настройки. По умолчанию используется `OPENROUTER_MODEL=openrouter/free`; доступность бесплатных моделей зависит от провайдера.

## Проверка

```powershell
npm test --workspaces
npm run typecheck --workspaces
npm run build --workspaces
docker compose exec db psql -U ai_gate -d ai_gate -c "SELECT session_id, prompt, answer, created_at FROM exchanges ORDER BY created_at;"
```

Проверьте в браузере появление ответа частями, локальную историю после обновления страницы и отсутствие чужой истории в отдельной сессии. [Подробный сценарий](specs/001-ai-gate-demo/quickstart.md) и [карта фич](docs/README.md) описывают результат и порядок проверки.

## Как устроено хранение

API читает ключ OpenRouter и реквизиты БД только из серверного окружения. Браузер получает подписанную анонимную cookie и хранит завершённую историю в `localStorage` под ключом текущей сессии. PostgreSQL хранит полные пары запрос–ответ с `session_id`. В текущем этапе UI восстанавливает историю из `localStorage`; чтение истории из БД и публикация запланированы после локальной проверки.
