# HTTP-контракт при публикации

Контракт остаётся прежним: [контракт 001](../../001-ai-gate-demo/contracts/api.md).

| Метод и путь | Публичный результат |
| --- | --- |
| `GET /api/session` | `sessionId` и подписанная HttpOnly cookie; ответ не кэшируется |
| `POST /api/chat` | JSON-ошибка до открытия потока либо SSE с `delta`, затем `done` только после записи в PostgreSQL; `error` при сбое |

Оба пути находятся на том же HTTPS-origin, что и интерфейс. Ключ OpenRouter и строка БД не входят в HTTP-ответы или браузерный bundle. Локальный Vite proxy сохраняется только для разработки.
