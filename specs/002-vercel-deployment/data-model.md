# Модель данных для публикации

Новых сущностей и миграций нет. Используется схема [первой спецификации](../001-ai-gate-demo/data-model.md).

| Сущность | Где хранится | Поля и связь |
| --- | --- | --- |
| Анонимная сессия | Подписанная HttpOnly cookie | UUID; связывает записи без учётной записи |
| Завершённый обмен | PostgreSQL, `exchanges` | `id`, `session_id`, `prompt`, `answer`, `created_at` |
| История интерфейса | `localStorage` конкретного origin | Завершённые пары текущего `session_id` |

`db/init.sql` применяется один раз к новой удалённой БД. Клиент не читает историю из PostgreSQL; после смены `localhost` на домен Vercel история браузера начинается пустой. Тестовые локальные строки не переносятся.
