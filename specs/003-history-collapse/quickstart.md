# Quickstart: проверить сворачивание истории

1. Откройте локально запущенный AI Gate по инструкции [локального запуска](../../docs/04-local-run.md) либо опубликованную версию после отправки коммита. Создайте два завершённых запроса, один с коротким ответом, другой с Markdown-заголовком или списком.
2. В панели истории каждая карточка сначала показывает только текст запроса и кнопку «Развернуть» справа. Ответ, его сырой Markdown и дата не видны.
3. Раскройте одну карточку: полный ответ отображается с Markdown-оформлением и датой, кнопка стала «Свернуть»; другая карточка остаётся закрытой.
4. Сверните карточку снова и обновите страницу: пары остались в истории, но обе карточки снова закрыты.
5. При узкой ширине окна (около 320–375 пикселей) проверьте карточку с длинным запросом: текст переносится внутри границ, а кнопка раскрытия видна и доступна.

Автоматическая проверка из корня репозитория: `npm run test -w apps/web -- App.test.tsx`. Новые запросы расходуют лимит бесплатной модели, поэтому после публикации достаточно коротких проверочных запросов.
