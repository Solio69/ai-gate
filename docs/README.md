# AI Gate — карта фич

Приложение принимает запрос без регистрации, показывает ответ по мере поступления и сохраняет завершённые пары в PostgreSQL и браузере. Согласованный объём описан в [спецификации](../specs/001-ai-gate-demo/spec.md).

| Фича | Результат | Состояние | Описание |
| --- | --- | --- | --- |
| 1. Анонимная сессия и форма | Запрос до 500 символов без учётной записи | Реализовано, проверки пройдены | [Подробнее](01-anonymous-session.md) |
| 2. Потоковый ответ ИИ | Текст появляется частями и в Markdown; ключ остаётся на сервере | Управляемый поток пройден; реальный ответ получен, поток отдельно не подтверждён | [Подробнее](02-ai-streaming.md) |
| 3. История | Полные пары в PostgreSQL и localStorage; все карточки сначала свёрнуты до заголовка запроса | Браузерная история и две сессии в БД проверены; проверки нового вида — в [журнале 003](../specs/003-history-collapse/verification.md) | [Подробнее](03-history.md) |
| 4. Локальный запуск | Приложение и БД запускаются на компьютере | Управляемый поток проверен; реальный ответ и запись в БД подтверждены пользователем | [Подробнее](04-local-run.md) |
| 5. Публикация на Vercel | Один адрес для интерфейса и API; Neon PostgreSQL | Сайт опубликован, таблица и индекс созданы; полный облачный сценарий ещё проверяется | [Подробнее](05-vercel-deploy.md) |

## Что проверено

- При исходной реализации прошли 24 теста API и 23 теста интерфейса. После правки истории прошли 24 теста интерфейса, проверка типов и сборка; результаты — в [журнале 003](../specs/003-history-collapse/verification.md). В число тестов API входят три интеграционных сценария с PostgreSQL.
- Прошли `npm test --workspaces`, `npm run typecheck --workspaces` и `npm run build --workspaces`.
- Контейнер PostgreSQL работает и проходит healthcheck. Проверены загрузка страницы, Vite proxy, выдача сессии и ответы API 400/503.
- В браузере на собранном интерфейсе с реальным API и PostgreSQL пройден сценарий с временным управляемым SSE upstream: первый фрагмент был виден до `done`, полный ответ и локальная история остались после обновления. Второй независимый cookie-клиент создал вторую запись; SQL показал две строки с разными `session_id`. Временный сервер и обе записи удалены.
- **Пользователь получил ответ настоящего OpenRouter и подтвердил запись в PostgreSQL.** Появление фрагментов реального ответа до завершения отдельно не подтверждено.

Публичная версия доступна по адресу [ai-gate-one.vercel.app](https://ai-gate-one.vercel.app/). Пользователь подтвердил успешный ответ. Проверки облачной записи и истории отслеживаются в [журнале деплоя](../specs/002-vercel-deployment/verification.md).
