# Фича 1. Анонимная сессия и форма

**Состояние:** реализовано; автоматические и доступные локальные проверки пройдены.

## Что видит пользователь

Страница открывается без входа. Форма показывает счётчик символов и причину отказа для пустого запроса или текста длиннее 500 символов. Enter отправляет запрос, Shift+Enter добавляет новую строку. Во время ответа повторной отправки нет. После успешного завершения поле очищается, а при ошибке или новом вводе во время ответа текст остаётся. После отправки допустимого запроса начинается получение ответа.

## Какие слои изменены

- **API:** `GET /api/session` создаёт или восстанавливает случайный ID. Подписанная cookie имеет `HttpOnly`, `SameSite=Lax` и `Path=/`; повреждённая cookie заменяется. `POST /api/chat` обрезает пробелы по краям и проверяет длину в Unicode-символах. ID из тела запроса не используется.
- **Интерфейс:** React-форма получает сессию перед показом рабочего экрана, считает символы так же, как API, и показывает ошибки ввода. Клавиатурная отправка идёт через ту же проверку формы, что и кнопка. Секрет подписи cookie не попадает в браузер.
- **Настройка:** сервер читает секрет подписи из локального `.env`. Для JSON установлен достаточный лимит тела; сверхлимитный запрос получает JSON-ошибку 413.

## Как проверено

Тесты API проверяют создание и повторное использование сессии, повреждённую cookie и границы ввода. Тесты интерфейса проверяют форму и сообщения об ошибке. Общий прогон дал **24/24 теста API** и **23/23 тестов интерфейса**. При локальном запуске проверены загрузка страницы, запрос сессии через proxy и ответы 400/503.

Для ручной проверки новой сессии откройте страницу в отдельном окне инкогнито и сравните поведение с обычным окном.
